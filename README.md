# portfolio

Personal portfolio — security tooling and secure web front-ends.
Static site: plain HTML/CSS/JS, self-hosted fonts, no build step, no third-party requests.
Features a small animated guide ("Pixel") and a warm cinematic theme.

## Run locally
```bash
python3 -m http.server 8000   # http://localhost:8000
```
## Deploy
Settings → Pages → Source: **GitHub Actions** (workflow in `.github/workflows/pages.yml`).
